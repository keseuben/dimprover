    Ezek a Developer Grid teljes munkaterére érvényesek. A munkahelyi / néma mód minden hallható jelzést azonnal letilt, a vizuális értesítések ettől függetlenül bekapcsolva maradhatnak.

    Értesítési diagnosztikaA Developer Grid Windows értesítése és a ChatGPT webes értesítése két külön rendszer.
    Developer Grid WindowsELLENŐRZÉSRE VÁRA worker-riasztások saját Electron/Windows csatornája.
    ChatGPT webesELLENŐRZÉSRE VÁRA chatgpt.com saját web-push / böngészős értesítése.

    A Developer Grid saját Windows értesítése akkor is működhet, ha a ChatGPT webes értesítése Electronban nem elérhető.

    Teszt:

    A teszt a valódi worker-eseményhez hasonlóan meghajtja a hangot, Windows értesítést, tálcavillogást és – ha engedélyezett – a bemondást.
