# 0.1.103 – eredeti felhasználói korlátok és szemantikus szerkesztő
A 0.1.102 Windows-próbán a BenjáminAI BOOT ACK szerveresen VALIDATED volt. A befagyasztott átadó MD elkészült. A bootstrap összefoglaló gépi USER eredményt mutatott az eredeti korlátok helyén; az új projektmező Ctrl+V nagybeillesztése composer-not-found hibát adott. Natív Shift+Insert működött. Az új csevegés ACK-ja megjelent, de a DOM health fail-closed blokkolta a visszakötést; teljes E2E még nincs igazolva.
A bootstrap külön megőrzi a befagyasztott eredeti sourcePrompt utasítást, a hiánya csak ACK-ra korlátoz. A DOM adapter támogatja a látható szemantikus textbox / main szerepeket is, változatlan üzenet-role/proof ellenőrzéssel. A hosszú Ctrl+V a composer hiányánál a felhasználó által fókuszált mező natív beillesztésére esik vissza.
A régi capsule/proof azonosítókat nem írjuk át és nem lazítjuk a backend kapuit. A jelenlegi új csevegésben a read-only korlátokat kézzel hozzáfűztük; az nem bizonyítja a javított verzió automatikus korlátmegőrzését. Új Windows E2E szükséges.
