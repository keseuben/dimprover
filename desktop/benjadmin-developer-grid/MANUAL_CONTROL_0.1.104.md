# v0.1.104 – Kézi vezérlés

Frissítés után mind a négy kódmérnök kézi módban indul. Central Core → KÉZI VEZÉRLÉS → kódmérnök kiválasztása.

Meglévő feladathoz: állapot frissítése; szükség esetén kapcsolat helyreállítása; folytatás előnézete; ellenőrzött üzenet elküldése. Az olvasási vagy DEV engedélyt külön kell megadni. A fázisjelentés elfogadása és a következő fázisutasítás külön gomb. Az eredeti tiltások érvényesek maradnak.

Új taskhoz: az ÚJ FEJLESZTÉSI FELADAT részben töltsd ki az utasítást, projektet és modult. A Launch Packet csak a kiválasztott workernek készül. Új projektcsevegésnél előbb hozz létre új csevegést a megfelelő ChatGPT Projektben, majd ÚJ CSEVEGÉS RÖGZÍTÉSE. A gépi piszkozat küldését a kézi lapon lehet elvégezni.

KÉZI MÓD / SZÜNET: megakadályozza az új automatikus műveleteket; egy már elindult szerverművelet befejeződhet. AUTOMATIKUS MÓD csak a kijelölt kódmérnöknél kapcsolható be.

A Windows-próba kiadáskor külön ellenőrzési lépés. Egységteszt nem igazolja a tényleges ChatGPT felület vagy a DEV kapcsolat működését.
