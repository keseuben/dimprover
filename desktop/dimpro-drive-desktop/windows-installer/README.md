# DIMPRO Drive Desktop V0.1.9 – Windows EXE installer

Cél: a végfelhasználó egyetlen DIMPRO_Drive_Desktop_Setup_V019.exe fájlt töltsön le és indítson el.

Az EXE:
- natív Windows mappaválasztót mutat;
- a V0.1.9 Open Handlert beépített erőforrásból telepíti;
- per-user HKCU alatt regisztrálja a dimpro-drive:// protokollt;
- elmenti a munkafájl-mappát;
- nem igényel rendszergazdai jogosultságot;
- nem végez teljes Drive-szinkront.

A munkafájl-mappa később a webes Drive Műveletek → Drive Desktop beállítások menüből módosítható.
